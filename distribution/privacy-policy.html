Privacy Policy

Learn By Marifat Team
Effective 14 September 2026

Data handled by the app

The app stores lesson progress, exercise answers, code drafts, settings, and portfolio notes locally on the learner's device. The app has no user accounts and does not transmit learner data to Marifat Software Team or a remote server. It contains no advertising, analytics, tracking SDK, cloud compiler, or telemetry service.

Backup and deletion

The learner chooses whether and where to export a local backup. Backups are readable JSON and are not encrypted. Clear the app's storage or uninstall it to delete local app data. Exported files must be deleted separately from their chosen location.

External links

The About page can open the Code With Safi YouTube channel in an external app. The external service's privacy terms apply after leaving this app. Learn By Marifat Team does not receive the learner's YouTube activity.

Permissions

The Android release does not request internet, location, camera, microphone, contacts, advertising ID, or notification permission. A system file picker is used only after the learner chooses to import or export a backup.

Children and learners

The app does not knowingly collect personal information from children or other learners. Portfolio fields should contain fictional or non-sensitive learning evidence. Teachers and guardians should guide younger learners when storing or sharing exported files.
