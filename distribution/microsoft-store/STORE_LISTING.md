## English

**Product name:** Learn By Marifat Team

**Short description:** Learn programming step by step, fully offline, in English, Dari and Pashto.

**Description:** Learn By Marifat Team is an offline programming education app created for Afghan computer science students and complete beginners. Follow a clear locked learning path from first concepts to advanced topics across Python, web design, web development, Java, Kotlin, Android, iOS, Swift, C++, JavaScript, React, React Native, Node.js, Express.js, Flutter, Dart and databases. Read detailed explanations, study examples, complete exercises, practise supported Python and SQL tasks, and save project evidence locally. No account, subscription, analytics or internet connection is required for the learning experience.

**Key features:**

- 20 offline courses, 320 modules and 60 project briefs
- English, Afghanistan Dari and Afghanistan Pashto
- Sequential lessons, progress, XP, achievements and encouraging feedback
- Offline Python and SQLite practice for supported exercises
- Local notes, code drafts, bookmarks and portable backups
- No ads, account, telemetry or cloud activation
