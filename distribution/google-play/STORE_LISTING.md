# Google Play store listing

## English

**App name (22/30):** Learn By Marifat Team

**Short description:** Learn programming offline in English, Dari, and Pashto.

**Full description:**

Learn programming step by step, even when an internet connection is unavailable.

Learn By Marifat Team provides 20 structured programming and database courses in English, Afghanistan Dari, and Afghanistan Pashto. Start with guided Python foundations, then continue through web, mobile, software development, and database learning paths.

Each course begins with essential vocabulary and a worked example. Lessons unlock in order so beginners always know what to do next. Practice activities, real-world project briefs, code drafts, progress, and portfolio notes stay available on the learner's device.

Features:
- 20 offline courses and 320 modules
- English, Dari, and Pashto learning content
- Guided explanations, examples, practice, and projects
- Sequential learning paths with clear prerequisites
- Offline Python foundation exercises and read-only SQLite practice
- Code workspace for supported course languages
- Local progress, bookmarks, drafts, and backup
- No account, advertising, analytics, or subscription

Some advanced projects require development tools installed separately. The app explains those requirements before the learner begins. YouTube is an optional external link and needs internet; the courses themselves remain offline.
