# Privacy Policy - Learn By Marifat Team

Effective date: 14 September 2026

Learn By Marifat Team is an offline programming education application developed by Marifat Software Team.

## Data handled by the app

The app stores lesson progress, exercise answers, code drafts, settings, and portfolio notes locally on the learner's device. This information is used only to provide learning, progress, backup, and restore features inside the app.

The app does not create user accounts and does not transmit learner data to Marifat Software Team or to a remote server. It contains no advertising, analytics, tracking SDK, cloud compiler, or telemetry service.

## Local backup and deletion

The learner decides whether to export a backup and chooses its destination using the device file picker. Exported backups are readable JSON files and are not encrypted. Learners should store them in a location they trust.

Local app data can be deleted by clearing the app's storage or uninstalling the app. An exported backup remains wherever the learner placed it and must be deleted there separately.

## External links

The About page can open the Code With Safi YouTube channel in an external browser or YouTube application. After leaving this app, the external service's privacy policy and data practices apply. The app does not receive the learner's YouTube activity.

## Permissions

The Android release does not request internet, location, camera, microphone, contacts, advertising ID, or notification permission. A system file picker is used only when the learner explicitly imports or exports a local backup.

## Children and learners

The app does not knowingly collect personal information from children or other learners. Portfolio fields should use fictional or non-sensitive learning evidence. Teachers and guardians should guide younger learners in storing and sharing exported files.

## Changes

Material changes to this policy will be included with an updated application release and reflected in the hosted policy used by the store listing.
