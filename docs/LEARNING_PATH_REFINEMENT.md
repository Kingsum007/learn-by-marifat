# Learning path refinement — 14 September 2026

Course pages expose all six workshops, including Python's previously reference-only advanced modules. Workshops are grouped through descriptive foundation, connected-skills, and advanced-practice labels. These labels describe study order, not an assessed qualification.

Each workshop now includes its existing learning objective, a link to review the preceding module, prediction guidance before the example, gradual practice instructions, debugging guidance, and an explicit readiness self-check. Next lesson navigation continues through the workshop sequence without awarding completion or XP. Python advanced practice comes directly from its authored curriculum task and review criterion. Global Python rewards appear only on the Python course page.

All added guidance has English, Dari, and Pashto entries. The translation inventory reports zero missing keys; this does not replace native educator review. This change improves sequencing and instructional scaffolding, not every course's subject-specific explanation. Many advanced examples still require the course's local development tools; only the existing supported Python and SQLite features execute inside the app.
