# Course UX refinement — 2.8.0

The course journey uses a single vertical list with consistent spacing and full-width cards. The previous alternating indentation and decorative connector were removed because long translated titles and enlarged text made the path harder to scan. Locked cards are disabled, name the required action, and cannot open a dead-end screen. Project cards follow the same rule.

Every non-Python course has a required introductory lesson before topic 1. The introduction assumes no vocabulary from that course, defines four terms, traces the smallest example, asks a readiness question, and provides guided practice, hint, reference result, troubleshooting, and an explicit completion action. Completion is stored in backup format version 4. Older backups remain readable; existing course evidence infers that its introduction was previously completed.

Python retains its seven longer interactive foundation lessons as its zero-knowledge entry. Course prerequisites, introductions, modules, activities, and projects remain sequentially locked. The independent Code Lab stays open for experimentation.
